Autoload'ы:
	GameEvents - выглядит как посредник
	HexGrid - чистый красивый
	TurnManager - 200+ строк, раздутый
	UIManager - Много повторяющегося кода, но не критично

Base Class:
	Actor - чистый
	Arena - слишком узконаправленная для своего масштаба
	ArenaCam - один метод, было много планов, но забил
	HealthComponent - повреждения брони уже есть, но внутрення структура просто healthbar
	Hex - неоптимизированный, но пока не вызывает лагов
	HexRigidbody - гексагональная физика, универсальный класс
	InspectionWindow - Окно имеющее возможность передвигать его, закрыть или свернуть/развернуть. Очень плохо написан
	ShipLayout - слишком много знает, руководитель
	ShipMediator - выглядит как посредник
	VectorVisualizer - показывает вектора, с работой справляется
	Visualizer - узконаправленный класс отображения векторно нарисованного корабля, еще занимается анимацией??

Data Class:
	Action - общий класс для действий доступных кораблю
	HexOrientation - хранит состояние поворота в гекс сетке и конвертирует между разными типами координат

Modules:
	Module - общий класс модуля, имеет прочность и статус активности
	Bulkhead - стандартный модуль который ничего не делает
	Controller - общий класс-модуль контроллеров
	PlayerController - дает управление кораблем игроку когда наступает его ход
	AIController - не начатый класс, который сам ходит в свой ход
	EngineModule - хранит информацию о двигательных способностях корабля, взаимодействует с HexRigidbody
	Weapon - общий класс-модуль оружия

Resources:
	ActorConfigs - конфиг актора пока что хранит только цвет корабля, начальную позицию и поворот
	EngineConfigs - конфиг хранящий возможности движения корабля (в будущем только возможности двигателя, которые будут по разному работать с разными кораблями)
	GameConfigs - хранит пока что только количество и конфиги акторов, а так же количество раундов
	Textures - хранит векторные текстуры (пока что только корабля)

Static Class:
	AxialUtilities - мой магнум опус, все необходимые инструменты для работы с гексами
	GlobalEnumerators - хранит глобальные enum

UI:
	WindowOpener - открывает окно инспекции обьекта (работает пока только с кораблями показывая окно с кучей текста)
	ShipContents - генерирует описание корабля (та самая стена текста)
